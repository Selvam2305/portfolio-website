🌐 Personal Portfolio Website

A responsive and modern personal portfolio website built to showcase my skills, projects, certificates, and contact information.

 ✨ Features

* Responsive and user-friendly design
* About Me section
* Skills showcase
* Projects section
* Certificates section
* Contact form
* Smooth navigation and interactive animations

 🛠️ Technologies Used

 Frontend

* HTML5
* CSS3
* JavaScript

 Backend

* Node.js
* Express.js
* MongoDB

 📂 Project Structure

```text
portfolio-website/
│
├── backend/          # Backend and API
├── certificates/     # Certificates
├── index.html        # Main HTML file
├── style.css         # Styling
├── script.js         # JavaScript functionality
├── portfolio.png     # Portfolio preview
└── README.md
```

 ✈️ Getting Started

 Clone the Repository


git clone https://github.com/Selvam2305/portfolio-website.git


 Navigate to the Project Folder


cd portfolio-website

 Run the Project

Open `index.html` in your browser.
